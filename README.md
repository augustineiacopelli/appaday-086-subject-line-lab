# AppADay 086 &middot; Subject Line Lab

Paste an email body and get five subject-line candidates, each measured for predicted open rate and generated by Claude.

**Live:** https://augustineiacopelli.github.io/appaday-086-subject-line-lab/
**Portfolio:** https://augustineiacopelli.github.io/appaday/

## What it does

Drop in the email you are about to send. Subject Line Lab reads what the email actually says and returns five distinct subject lines, each taking a different angle: a benefit line, a curiosity line, an urgency line, a question, a plain direct line. Every candidate comes back as a "reading" with:

- a predicted-open score from 0 to 100, shown on a live gauge and ranked best first,
- the technique it uses, named in a word or two,
- a one-line reason it works,
- a character count that flags lines likely to truncate on a phone,
- a one-tap copy button.

The strongest candidate is marked as the top pick. An optional audience field and a saved sender or brand voice let you tune the results toward who is actually receiving the email.

## How it is built

A single self-contained `index.html` of vanilla HTML, CSS, and JavaScript. No build step and no dependencies beyond Google Fonts (Fraunces, Space Grotesk, Inter). The interface is a measurement instrument: a clinical cool palette, a serif wordmark used with restraint, and instrument-style numerals on every score and gauge.

It is AI-powered. The app calls the Anthropic Messages API directly from the browser using your own API key, which is stored only in your browser's local storage and sent only to Anthropic when you run the lab. Add your key in Settings (the gear icon). The model is `claude-sonnet-5`.

Scores are AI estimates of relative open likelihood based on subject-line craft, not guaranteed rates. Use them to compare candidates and pick a direction, then test what matters with your own audience.
